# Windows 维护与残留清理

设置中的“维护”页面由 Hub 提供。扫描、备份查询、清理和恢复由 `core/connect-hub-cleanup.exe` 按任务运行，结束后退出。没有安装组件时页面显示不可用，基础 VPN 仍可使用。打开页面不会自动扫描或启动组件。

## 使用流程

1. 点击“扫描残留”，查看已安装客户端及残留。建议先打开 Windows 卸载设置，完成官方卸载，再重新扫描。
2. 断开 VPN、关闭网络接管，勾选要处理的条目。深度项默认不选。点击“备份并清理所选项”，核对说明后确认。
3. 需要恢复时点击“查询备份”，选中备份并确认恢复。只有清理、恢复请求管理员授权；扫描和查询使用当前权限。
4. 取消任务会等待当前单项操作完成。关闭维护页面会取消只读任务；已确认的清理或恢复仍继续，并可重新打开页面查看状态。

备份保存已支持的文件、注册表、证书及策略值数据，不能替代系统还原点。防火墙和浏览器策略按选中的单条值恢复，保留其他规则；保留字符串及可展开字符串类型。已卸载的驱动、服务、Winsock 组件或应用可能需要重新安装。程序不承诺所有清理动作都能一键无损撤销。

结果中的“已不存在/跳过”表示对象在执行前已消失等无需重复处理的情况。“重启生效”不表示对象已经消失：占用文件可能仍在，服务也可能处于待删除状态。完成重启后重新扫描。恢复备份不会撤销 Windows 已登记的延迟删除；需要恢复这类文件时，应先完成重启，再恢复或重新安装客户端。程序不会自动重启电脑。

## 数据与恢复

- 使用 Hub 当前数据目录，包括 `CONNECT_HUB_HOME` 的显式覆盖。备份位于 `cleanup/backups`，任务记录位于 `cleanup/tasks`。
- 每项任务有独立的受限目录。成功扫描供本页选择使用；重新扫描、执行完成或关闭页面后释放扫描详情。清理/恢复记录及备份保留，不随页面关闭或程序升级删除。
- 页面最多展示 500 个扫描条目、100 个备份摘要及 128 条进度。完整计划和修改日志保存在任务目录；达到展示上限时会提示。
- 程序异常退出后，查询备份会提示没有最终确认的历史修改任务。不会自动重试清理。请核对记录与备份，必要时重新安装官方客户端。
- 历史备份清单版本 1 和清理计划版本 2 保持可读取。新备份增加随机标识以防同秒覆盖，并保存证书的用户/计算机范围。
- 不覆盖已有同名配置或备份。未迁入当前数据目录的历史备份可继续使用独立工具的 `--backup-dir`、`--restore` 参数访问。

## 构建与兼容

Windows 统一构建入口自动生成清理程序；完整包校验 CLI 协议 `2` 以及任务能力 `cleanup-task-v1`。GUI 的任务协议另用 `internal/components` 版本 `1`，不改变 Worker IPC 或 LAN 分享协议。Linux/macOS 不显示维护入口，也不发布清理程序。

工具保留 `--scan`、`--out`、`--apply`、`--restore`、`--list-backups`、`--backup-dir`、`--report`、`--only`、`--skip` 等命令行入口。GUI 使用独立任务模式；缺少或版本不兼容的程序不会退回 Hub 内执行清理。
