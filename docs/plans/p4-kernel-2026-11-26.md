## 未覆盖范围

本阶段未执行 aTrust 或 EasyConnect 真实网关登录，也未验证真实验证码/企业微信交互、提权网卡创建、路由安装或吞吐。内核代码测试不等同于网关兼容性验收，正式发布前仍需按设备和账号条件补做实机验证。

## 检出与构建

新检出需初始化固定内核子模块：

```powershell
git submodule update --init --recursive
go run ./scripts/buildtool -action check
go test -mod=readonly ./...
```

构建工具要求 `packaging/build-inputs.json` 中指定的 Go 版本，并校验 Hub/内核提交、子模块干净状态、模块清单及 IPC 生成结果。不要把外层工作区 `go.work` 或 `go.work.sum` 纳入产品提交。
